# Fonts

All fonts here are licensed under the SIL Open Font License 1.1 (full text: [OFL-LICENSE.txt](OFL-LICENSE.txt)).
The cards do not load them at runtime: `frontend/scripts/build-font.cjs` turns them into LED bitmaps
(`frontend/src/font-data.js`).

| File | Font | Author | Source | Used for |
|---|---|---|---|---|
| `LondonUnderground-Regular.ttf` | London Underground dot-matrix typeface | petykowski | https://github.com/petykowski/London-Underground-Dot-Matrix-Typeface | Tube platform board |
| `Dot Matrix Regular.ttf` | Dot Matrix Typeface (Regular) | Daniel Hart | https://github.com/DanielHartUK/Dot-Matrix-Typeface | station boards, bus Countdown |
| `Dot Matrix Bold Tall.ttf` | Dot Matrix Typeface (Bold Tall) | Daniel Hart | https://github.com/DanielHartUK/Dot-Matrix-Typeface | station board clock |
